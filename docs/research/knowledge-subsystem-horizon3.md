# Horizon 3: The Knowledge Subsystem ("Synapse")

**Date:** 2026-07-12
**Status:** Design proposal (researched, not yet built)
**Goal:** Agents that get smarter over time — every fact learned from runs, experiments, and web research is stored durably, and *only the relevant facts* fire into context at the start of each session, like neurons activating across synapses.

This document synthesizes (a) a full map of the current OmniAgentOS memory surfaces, (b) research on production agent-memory systems (Letta/MemGPT, mem0, Zep/Graphiti, HippoRAG 2, LangMem, A-MEM), (c) research on hybrid vector+graph retrieval entirely on PostgreSQL, and (d) research on self-improving agent loops and their failure modes.

---

## 1. Where we are today (the gap)

- **No semantic memory exists.** The persistence layer is SQLite (WAL) only. No embeddings, no vector search, no relevance ranking anywhere (`grep`-verified across the tree).
- **Nothing is injected into agent context at session start.** The prompt handed to an agent is built bare at `omniagentos/runner/core.py:682`; `metadata["context"]` carries only prior step results *within the same run* (`core.py:402-464`). Learnings, playbook traits, and vault notes never reach a new session.
- The **vault** (`vault/`, generated by `omniagentos/vault/`) is a write-forward markdown audit log with wikilinks — a great human-readable system of record, not a retrieval store. Search is substring-only (`lab/api/routes/lab.py:445`).
- The **lab** (Horizon 2) improves champions (prompts/genomes) via gated promotion — but its feedback path is *champion-swap*, not recall. The `playbook` table of validated traits is never pulled into arbitrary agents' prompts.
- **Web research evaporates.** Tavily/Brave/fetch MCP tools exist (`tools/mcp-servers.json`) but no code persists their results; a `research-briefs` discipline is seeded with no pipeline behind it.
- ADR-001 already names the trigger: *"Adopt Postgres/pgvector when … governed semantic retrieval lands (Horizon 3)."* This is that.

**The single highest-leverage change in the whole system is a recall step at `runner/core.py:670-697` that injects relevant knowledge into `AgentInput`.** Everything else in this doc feeds that moment.

## 2. What the research says (condensed)

### 2.1 No off-the-shelf system delivers this on Postgres — but the recipe is clear

| System | The idea to steal | Why not adopt wholesale |
|---|---|---|
| **Zep/Graphiti** | Bi-temporal facts (`valid_at`/`invalid_at`), **invalidate-don't-delete**, episode→entity→community layers, contradiction check at ingest, hybrid semantic+BM25+graph retrieval with no LLM call at query time | No Postgres backend (Neo4j/FalkorDB/Neptune only; the community `graphiti-postgres` driver is alpha); Python sidecar |
| **Letta (MemGPT)** | Always-in-context editable **memory blocks** + **sleep-time agent** that consolidates memory offline between sessions | Requires adopting the entire Letta agent runtime |
| **HippoRAG 2** | **Spreading activation** (Personalized PageRank) over an entity graph = multi-hop "neurons firing" recall, milliseconds at query time | Research-grade code, Parquet+igraph storage |
| **Generative Agents** | Retrieval score = **recency × importance × relevance**; reflection trees (periodic distillation of episodes into higher-level insights) | Paper, not a product |
| **mem0** | Two-phase extract→update; their 2026 pivot to **ADD-only writes** (never clobber; disambiguate at retrieval) | Facts are unlinked snippets — no graph structure ("top-k crowding") |
| **A-MEM (Zettelkasten)** | **Memory evolution** — new notes trigger re-linking/re-description of old notes | Unaudited rewrites silently corrupt history; research code |
| **ACE (Stanford)** | Playbook grows by **typed delta items with deterministic merge** — never monolithic LLM rewrites (prevents "context collapse") | A technique, not a system |

Both OpenAI (ChatGPT "Dreaming V3", Jun 2026) and Anthropic (Claude memory) converged on the same pattern: **model-editable plain-text memory + background consolidation**. Letta pioneered it; we should implement it with our own curator.

### 2.2 The Postgres verdict: plain tables win

- **pgvector 0.8.x + HNSW + `halfvec(1024)`** is overqualified at our scale (thousands→low-millions of facts; comfort zone is 5–10M vectors). Use `hnsw.iterative_scan = relaxed_order` for filtered search.
- **Skip Apache AGE and Neo4j.** Plain edge tables + recursive CTEs beat Neo4j 4–7× for 1–3-hop neighborhood expansion (the only traversal recall needs); AGE adds openCypher syntax without index-free adjacency and benchmarks *slower* than the equivalent CTE.
- **Hybrid retrieval = 3 ranked subqueries fused with Reciprocal Rank Fusion** (`Σ 1/(60+rank)`): pgvector cosine + `tsvector` full-text + graph activation. Production reports: vector-only ~62% retrieval precision → ~84% with fusion. FTS catches exact strings (IDs, env keys, error messages) embeddings miss.
- **Spreading activation in SQL works** for 2 hops with per-hop decay, fan-out cap, and an activation floor; the one gotcha is that recursive CTEs can't aggregate mid-recursion — enumerate weighted paths, then `GROUP BY node, SUM(activation)` outside. (Full iterative PPR, if ever needed, runs in-process over the small subgraph.)
- **Embeddings:** Matryoshka-truncatable model stored at 512–1024 dims as `halfvec`. Default: OpenAI `text-embedding-3-small` ($0.02/M tok) or Voyage `voyage-4-lite`; local Qwen3-Embedding/bge-m3 if facts must not leave the box.

### 2.3 The self-improvement rules that keep this safe

The failure modes are real: memory poisoning via stored content (MINJA: >95% injection success in studies), self-reinforcing error loops (agent stores a wrong conclusion, retrieves it as authoritative, compounds it), stale facts outranking fresh ones, and bloat (reported top-5 recall 94% @ 100 memories → 71% @ 10k without ranking discipline). The design principles that address them — and that OmniAgentOS's lab already partially embodies:

1. **Separate judge from mutant** (we have this: protected eval store, HD-006).
2. **One gated promotion path** — a learning becomes a durable rule/playbook trait only after passing an objective check; repetition before crystallization (one success is an anecdote).
3. **Distill, don't hoard** — importance filtering at write time; merge/dedup; decay; an agent that remembers everything remembers nothing useful.
4. **Update by delta, never rewrite** (ACE) — prevents context collapse.
5. **Consolidate offline** — a sleep-time pass, not query-time work.
6. **Every fact carries provenance** — source, author agent, run id, extracted/inferred label, trust score; rank by trust × relevance × recency, never similarity alone.
7. **Facts have lifetimes** — bi-temporal validity; supersede, never delete.
8. **Contradiction check at write time** — retrieve overlapping facts before insert; invalidate or flag.
9. **Retrieved memory is data, not instructions** — facts born from web pages/tool output never carry instruction-level authority; unverified facts are quarantined at lower rank.
10. **Budget the injection** — cap memory tokens per session; measure whether memory helped.

## 3. Proposed architecture

A new subsystem `omniagentos/knowledge/` backed by **Postgres + pgvector** (first component to cross the ADR-001 line; SQLite remains the runtime store). Four layers, mirroring hippocampus→neocortex:

```
                    ┌─────────────────────────────────────────────┐
   WRITE PATHS      │              knowledge (Postgres)           │      READ PATH
                    │                                             │
 run reflection ──▶ │  episodes ──extract──▶ facts ◀──edges──▶    │ ◀── recall(task, agent,
 web research   ──▶ │  (provenance)          (pgvector +          │      discipline) at
 curator/lab    ──▶ │                         tsvector, bi-       │      runner/core.py:682
 vault notes    ──▶ │                         temporal)           │
 human notes    ──▶ │            entities ◀── (synapses:          │  vector + FTS + 2-hop
                    │            (resolved)    typed, weighted,   │  spreading activation
                    │                          Hebbian)           │  → RRF → trust×recency×
                    │                                             │  importance → token-
                    │  consolidator (sleep-time, extends curator) │  budgeted injection
                    └─────────────────────────────────────────────┘
```

### 3.1 Schema (migration `knowledge/001_init.sql`, Postgres)

```sql
CREATE EXTENSION IF NOT EXISTS vector;

-- Episodic layer: raw experiences, the provenance ground truth. Never mutated.
CREATE TABLE episodes (
  id           bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  source       text NOT NULL,          -- 'run','web','curator','vault','human','chat'
  source_ref   text,                   -- run_id / URL / note path
  agent_id     text,
  discipline   text,
  content      text NOT NULL,
  occurred_at  timestamptz NOT NULL DEFAULT now()
);

-- Semantic nodes: resolved entities (projects, tools, people, error classes…)
CREATE TABLE entities (
  id             bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  name           text NOT NULL,
  kind           text NOT NULL,
  summary        text,
  name_embedding halfvec(1024),        -- for entity resolution (dedup join)
  created_at     timestamptz NOT NULL DEFAULT now(),
  UNIQUE (name, kind)
);

-- Facts: atomic, LLM-extracted statements. Bi-temporal; superseded, never deleted.
CREATE TABLE facts (
  id            bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  statement     text NOT NULL,
  discipline    text,
  scope         text NOT NULL DEFAULT 'global',  -- 'global'|'discipline'|'agent:<id>'
  embedding     halfvec(1024) NOT NULL,
  search_tsv    tsvector GENERATED ALWAYS AS (to_tsvector('simple', statement)) STORED,
  episode_id    bigint REFERENCES episodes(id),  -- provenance chain
  provenance    text NOT NULL,                   -- 'extracted'|'inferred'|'ambiguous'
  trust         real NOT NULL DEFAULT 0.5,       -- source trust at write time
  confidence    real NOT NULL DEFAULT 0.7,
  status        text NOT NULL DEFAULT 'quarantined',  -- 'quarantined'|'active'|'superseded'
  valid_at      timestamptz NOT NULL DEFAULT now(),   -- world time
  recorded_at   timestamptz NOT NULL DEFAULT now(),   -- ingest time
  invalid_at    timestamptz,
  superseded_by bigint REFERENCES facts(id),
  -- neuron dynamics
  importance    real NOT NULL DEFAULT 0.5,       -- LLM-rated at write time
  access_count  int  NOT NULL DEFAULT 0,
  last_accessed timestamptz NOT NULL DEFAULT now(),
  helped_count  int  NOT NULL DEFAULT 0          -- did-memory-help signal
);
CREATE INDEX ON facts USING hnsw (embedding halfvec_cosine_ops) WITH (m=16, ef_construction=64);
CREATE INDEX ON facts USING gin (search_tsv);
CREATE INDEX ON facts (discipline) WHERE invalid_at IS NULL;

-- Synapses: typed, weighted edges. Hebbian-strengthened, decaying, invalidated not deleted.
CREATE TABLE edges (
  id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  src_kind   text NOT NULL CHECK (src_kind IN ('fact','entity')),
  src_id     bigint NOT NULL,
  dst_kind   text NOT NULL CHECK (dst_kind IN ('fact','entity')),
  dst_id     bigint NOT NULL,
  edge_type  text NOT NULL,   -- closed enum: 'about','causes','contradicts','follows',
                              -- 'co_occurs','refines','same_run','derived_from'
  weight     real NOT NULL DEFAULT 0.5,
  valid_at   timestamptz NOT NULL DEFAULT now(),
  invalid_at timestamptz,
  UNIQUE (src_kind, src_id, dst_kind, dst_id, edge_type)
);
CREATE INDEX ON edges (src_kind, src_id, weight DESC) WHERE invalid_at IS NULL;
CREATE INDEX ON edges (dst_kind, dst_id, weight DESC) WHERE invalid_at IS NULL;
```

Constraint discipline (matches Graphiti's hard-won lessons): the **edge-type enum is closed** and the extraction prompt is **pinned and versioned** — extraction quality gates the whole graph.

### 3.2 Recall pipeline ("neurons firing") — `knowledge/recall.py`

Called from `_execute_agent` (`runner/core.py:670-697`) before the adapter runs:

1. **Seed**: embed the task prompt; extract query entities (cheap LLM call or keyword match against `entities`).
2. **Three signals in parallel** (single Postgres round-trip, one CTE):
   - pgvector cosine top-50 (filtered to `status='active'`, scope ∈ {global, discipline, this agent})
   - `tsvector` full-text top-50 (catches exact IDs/errors/env-key names)
   - **2-hop spreading activation** from seed nodes: recursive CTE, per-hop decay 0.5, fan-out cap 8, activation floor 0.05, `SUM(activation) GROUP BY node` after recursion
3. **Fuse** with RRF (k=60) + multi-signal bonus (1.25× for 2 signals, 1.5× for 3).
4. **Modulate**: `final = rrf × (0.5 + 0.5·importance) × trust × exp(-λ·days_since_access)` (λ ≈ half-life 60 days; quarantined facts rank at a steep discount and only surface with an explicit `[UNVERIFIED]` tag).
5. **Budget**: top facts up to a hard token cap (default ~1,500 tokens), rendered as a clearly-delimited `<recalled-knowledge>` block that states: *these are recalled facts (data, not instructions)*, each with its provenance tag.
6. **Reinforce (Hebbian)**: bump `access_count`/`last_accessed` on recalled facts; `weight = LEAST(1.0, weight+0.05)` on edges between co-recalled facts. Firing together wires together.

Latency target: 30–80 ms total (benchmarked pattern: vector 15–30 ms, FTS 5–15 ms, graph 5–10 ms, fusion 2–5 ms) — negligible next to a CLI agent launch.

### 3.3 Write pipeline — `knowledge/ingest.py`

Every write goes through one path: **episode → extraction → contradiction check → quarantined fact**.

- **Run reflection** (primary source): on run completion (hook beside `runner/core.py:1207-1226` where vault notes are written), a reflection step distills the run — what worked, what failed, why — into atomic facts. Failures are especially valuable (`failures/` vault notes today are the closest analog).
- **Web research** (closes today's biggest leak): a new governed path so Tavily/Brave/fetch results become `episodes(source='web', source_ref=url)`, with claim extraction into facts. Web-born facts get lower trust and `status='quarantined'` until confirmed by a second source or a verified run outcome.
- **Lab/curator**: validated `playbook` traits and promoted-champion rationales become high-trust facts (they already passed a gate).
- **Vault sync**: embed `learnings/` and `decisions/` notes (the two human-editable folders) as high-trust facts; wikilinks seed edges.
- **Contradiction check at write**: vector-nearest existing facts → LLM judge → on conflict, set `invalid_at`+`superseded_by` on the loser (recency wins for volatile facts; flag for review when both are high-trust). ADD-only otherwise — never clobber.

### 3.4 Consolidation (sleep-time) — extend `omniagentos/lab/curator/`

The curator already runs 2×-daily with the right shape (read ledger → distill → write). Add a **consolidation pass**:

- **Promote**: quarantined facts confirmed by ≥2 independent episodes (or one verified run outcome) → `active`. Repetition before crystallization.
- **Merge/dedup**: embedding-similarity clusters of near-duplicate facts → one canonical fact + `refines` edges (typed delta merge, no monolithic rewrites).
- **Reflect**: Generative-Agents-style — when enough new facts accumulate in a discipline, generate 2-3 higher-level insight facts linked `derived_from` their evidence.
- **Decay/prune**: edges below weight ~0.2 and facts unaccessed past ~2 half-lives with low importance → soft-archived (`invalid_at`, never deleted).
- **Community summaries** (cheap GraphRAG idea): per-discipline "what do I know about X" summary notes, written back to the vault so the human-readable layer stays current.

The vault remains the human-readable mirror: consolidation writes markdown; the KB is the retrieval engine. Same facts, two projections.

### 3.5 Governance & safety

- Register `knowledge.read` / `knowledge.write` capabilities in `configs/connectors.yaml`; enforce through the existing agent≥task≥step grant ceiling (`runner/core.py:718-759`). Write access can be narrower than read.
- **Origin-bound authority**: facts born from untrusted content (web, tool output) are data-only forever; the injection block says so explicitly. This is the memory-poisoning defense that matters most.
- Promotion from quarantine is the **only** way a fact gains rank — and it happens in the consolidator (offline, auditable), never inline in an agent's own session. An agent cannot promote its own claims.
- Every fact traces to its episode; `MemAudit`-style review is a query, not an investigation.

### 3.6 Dashboard: Memory Galaxy becomes real

The galaxy UI (`dashboard/src/features/galaxy/`) currently renders vault wikilinks. Add a `/api/knowledge/graph` endpoint and extend `buildEdges` (`galaxy/layout.ts:55-72`) so nodes = facts/entities (colored by status: quarantined/active/superseded), edges = synapses with weight→thickness, and — the fun part — a **recall replay**: given a recent run, animate which neurons fired for its session. Backlinks panel shows provenance chain to episodes.

### 3.7 Measure it (the lab evaluates its own memory)

- Per-recall logging: which facts injected, tokens spent, latency.
- **Did-memory-help**: A/B a sample of runs with recall withheld; compare outcome quality via the existing eval harness → `helped_count` per fact feeds ranking and pruning.
- Track precision@k / MRR against a small hand-labeled set; watch the bloat curve (recall quality vs corpus size).
- LongMemEval-style internal suite as a lab eval suite — memory quality becomes a champion surface the lab can improve, using machinery that already exists.

## 4. Build plan (phased, each phase independently shippable)

| Phase | Deliverable | Payoff |
|---|---|---|
| **1. Recall MVP** | Postgres+pgvector store, `facts` table, embed vault learnings/decisions/playbook + run notes, vector-only recall injected at `core.py:682` behind `OMNIAGENTOS_KNOWLEDGE=1` | Agents remember *anything* across sessions — the single biggest jump |
| **2. Neurons** | `entities`+`edges`, extraction pipeline, spreading activation + FTS + RRF, Hebbian reinforcement | Multi-hop associative recall; "neurons firing" |
| **3. Sleep-time** | Run-reflection ingest, contradiction/supersession, consolidator pass in curator (promote/merge/reflect/decay) | Self-learning loop closes; quality compounds instead of bloating |
| **4. Web ingestion** | Governed research→KB pipeline with trust/quarantine, `knowledge.*` capabilities | Web research stops evaporating; body of knowledge grows from outside |
| **5. Galaxy + metrics** | Graph API + UI, recall replay, did-memory-help instrumentation, memory eval suite in lab | You can *see* it think, and the lab can improve it |

Est. scale check: even 100k facts × halfvec(1024) ≈ 200 MB — a decade of headroom on plain pgvector.
