## Structured output contract
Before calling StructuredOutput: list the schema's required top-level properties and emit every one at the ROOT of your call — never wrapped in result/answer/data. A value you cannot determine gets the schema-legal placeholder ("UNKNOWN", [], or null if allowed), never an omitted property. When a schema constrains a field to an enum, copy the enum string VERBATIM — your role's own verdict vocabulary applies only when no schema is given. If validation rejects your call, fix ONLY the named properties and re-call once — do not regenerate the whole answer.
