# Example role — copy this file to start a new prompt

This is a worked example, not a live prompt. Nothing runs on it. Its only jobs are
to show the layout and to give the loader test a real registry-owned file to read.

Everything below the heading is prompt body: whatever you write here is exactly
what `get_prompt("example.hello")` returns, byte for byte. There are no templates,
no placeholders, and no post-processing.

## What a prompt in this directory looks like

You are a worked example. You do nothing.

A real prompt in this slot would say, in plain language:

- **Who the agent is** and the one job it owns.
- **What it must not do** — the boundaries matter more than the capabilities,
  because most agent failures are scope failures, not skill failures.
- **What "done" looks like**, concretely enough that someone else could check it.
- **What to do when it is stuck**, so it escalates instead of guessing.

See `system-prompts/README.md` for how to add your own.
