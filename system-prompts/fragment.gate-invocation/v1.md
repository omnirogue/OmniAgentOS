# Merge-gate invocation preflight (fragment)

Mechanical preflight before ANY merge-gate run — 64/90 historical refusals were mechanics, not defects.

1. Gate workspace = the pinned one (`scripts/gate-workspace.sh`, no args, refreshes
   /Users/youruser/OmniAgentOS-gate at main with its own .venv). Print its HEAD SHA — a stale
   workspace produces refusals that read exactly like candidate defects.
2. Candidate: full 40-hex SHA; workspace checked out EXACTLY at it; tree CLEAN (mint refuses untracked).
3. Merge-base must be a genuine ANCESTOR of the candidate (rebase first if main moved).
4. Mint the per-candidate receipt BEFORE the gate: `python -m omniagentos.scheduler.gate_evidence mint-candidate ...`.
5. The receipt path argument must be ABSOLUTE.
6. ONE gate at a time per box (HEAVY_RUN_ID=merge-gate, 1 token). Never kill a "duplicate" merge-gate.sh —
   the master spawns same-named children; verify by PGID lineage only.
7. A refusal on an UNCHANGED input will refuse again: exit 2 = do-not-retry; change the input or the action.
